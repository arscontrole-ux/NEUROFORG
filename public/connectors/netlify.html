Connecteur Netlify Serverless

Déployez NEUROFORGE sur Netlify avec fonctions serverless, formulaires intégrés et edge functions. Déploiement continu depuis Git.

Déploiement en 3 étapes

1 Connectez votre dépôt

Sur app.netlify.com :

  • Cliquez sur Add new site → Import an existing project
  • Choisissez GitHub, GitLab ou Bitbucket
  • Sélectionnez votre dépôt NEUROFORGE
2 Configurez le build

Netlify détecte automatiquement Vite, mais vérifiez :

Build command: npm run build
Publish directory: dist
Node version: 20
3 Déployez

Cliquez sur Deploy site. Netlify :

  • ✅ Build le projet
  • ✅ Déploie sur https://nom-aléatoire.netlify.app
  • ✅ Configure le HTTPS automatique
  • ✅ Active les re-déploiements sur chaque push

Configuration netlify.toml

Créez netlify.toml à la racine pour un contrôle total :

[build]
  command = "npm run build"
  publish = "dist"

[build.environment]
  NODE_VERSION = "20"

# Redirects pour SPA
[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

# Headers de sécurité
[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"

# Fonctions serverless (optionnel)
[functions]
  directory = "netlify/functions"

Pour tester localement avec les fonctions serverless :

# Installation
npm install -g netlify-cli

# Développement avec fonctions
netlify dev

# Déploiement manuel
netlify deploy --prod
