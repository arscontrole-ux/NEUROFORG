Connecteur GitHub CI/CD

Déployez NEUROFORGE automatiquement sur GitHub Pages à chaque push. Build, test et publication en moins de 60 secondes.

Configuration en 3 étapes

1 Créez un dépôt GitHub

Créez un nouveau dépôt public ou privé sur GitHub, puis poussez votre code :

git init
git add .
git commit -m "Initial NEUROFORGE"
git branch -M main
git remote add origin https://github.com/VOTRE_USER/neuroforge.git
git push -u origin main
2 Activez GitHub Pages

Dans les paramètres du dépôt :

  • Allez dans Settings → Pages
  • Source : Deploy from a branch
  • Branche : gh-pages / / (root)
  • Sauvegardez
3 Créez le workflow CI/CD

Créez le fichier .github/workflows/deploy.yml :

name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      
      - name: Install dependencies
        run: npm ci
      
      - name: Build
        run: npm run build
      
      - name: Setup Pages
        uses: actions/configure-pages@v4
      
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'
      
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4

Résultat

À chaque push sur main, GitHub :

  • ✅ Installe les dépendances
  • ✅ Lance le build (Vite)
  • ✅ Déploie sur https://VOTRE_USER.github.io/neuroforge/
  • ⏱ Durée totale : ~45 secondes
