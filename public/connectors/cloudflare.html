Connecteur Cloudflare Pages Edge Global

Déployez NEUROFORGE sur Cloudflare Pages avec distribution mondiale sur 300+ data centers. Latence ultra-faible, SSL automatique, bande passante illimitée.

Déploiement en 4 étapes

1 Connectez votre dépôt Git

Sur dash.cloudflare.com :

  • Allez dans Workers & Pages → Create
  • Choisissez Pages → Connect to Git
  • Sélectionnez votre dépôt GitHub/GitLab
2 Configurez le build

Paramètres de build :

Framework preset: Vite
Build command: npm run build
Build output directory: dist
Root directory: /
3 Variables d'environnement (optionnel)

Ajoutez si nécessaire :

NODE_VERSION: 20
NODE_ENV: production
4 Déployez

Cliquez sur Save and Deploy. Cloudflare :

  • ✅ Build le projet
  • ✅ Déploie sur https://votre-projet.pages.dev
  • ✅ Active le SSL global automatiquement
  • ✅ Configure les re-déploiements automatiques

Avantages Cloudflare

  • 🌍 300+ data centers dans le monde
  • ⚡ Latence < 50ms partout
  • 🔒 SSL/TLS automatique
  • 📊 Bande passante illimitée
  • 🔄 Preview deployments pour chaque PR
  • 🛡️ DDoS protection incluse
