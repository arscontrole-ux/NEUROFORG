Connecteur MCP Model Context Protocol

Intégrez NEUROFORGE avec le Model Context Protocol — le standard ouvert pour connecter vos modèles locaux à Claude, Cursor, et tous les clients MCP compatibles.

Qu'est-ce que MCP ?

Model Context Protocol est un protocole standardisé créé par Anthropic pour permettre aux assistants IA d'accéder à des outils, ressources et modèles externes. Avec MCP, NEUROFORGE devient un serveur de contexte accessible par :

🤖 Claude Desktop

Utilisez vos modèles locaux directement dans Claude

💻 Cursor IDE

Intégrez l'inférence locale dans votre éditeur

🔧 Outils MCP

N'importe quel client compatible MCP

🌐 API REST

Exposition HTTP/JSON pour vos scripts

Configuration en 3 étapes

1 Activez le serveur MCP dans NEUROFORGE

Dans l'onglet Système → Serveur local, activez le mode MCP :

# Le serveur MCP écoute sur le port 3333
# Protocole : JSON-RPC 2.0 sur stdio ou HTTP
MCP_PORT=3333
MCP_TRANSPORT=stdio|http
2 Configurez votre client MCP

Ajoutez NEUROFORGE comme serveur MCP dans votre client. Exemple pour Claude Desktop :

// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "neuroforge": {
      "command": "npx",
      "args": ["-y", "@neuroforge/mcp-server"],
      "env": {
        "NEUROFORGE_URL": "http://localhost:1234",
        "NEUROFORGE_MODEL": "llama-3.1-8b-instruct:Q4_K_M"
      }
    }
  }
}
3 Utilisez vos modèles locaux

Dans Claude Desktop ou tout client MCP, vous pouvez maintenant :

  • 🔍 Tools : appeler vos modèles comme des outils
  • 📚 Resources : accéder aux modèles chargés
  • 💬 Prompts : templates de prompts pré-configurés

Exemples d'utilisation

Tool : inférence locale

// Appel MCP depuis Claude Desktop
{
  "method": "tools/call",
  "params": {
    "name": "neuroforge_infer",
    "arguments": {
      "prompt": "Explique le téléchargement multi-parties",
      "model": "llama-3.1-8b-instruct:Q4_K_M",
      "temperature": 0.7,
      "max_tokens": 512
    }
  }
}

Resource : liste des modèles

// Lister les modèles disponibles
{
  "method": "resources/read",
  "params": {
    "uri": "neuroforge://models"
  }
}

// Réponse
{
  "contents": [{
    "uri": "neuroforge://models",
    "mimeType": "application/json",
    "text": "[
      {\"id\": \"llama-3.1-8b-instruct\", \"quant\": \"Q4_K_M\", \"loaded\": true},
      {\"id\": \"mistral-7b-v0.3\", \"quant\": \"Q5_K_M\", \"loaded\": false}
    ]"
  }]
}

Serveur MCP standalone

Pour un usage avancé, installez le serveur MCP NEUROFORGE :

# Installation globale
npm install -g @neuroforge/mcp-server

# Lancement en mode stdio (pour Claude Desktop)
neuroforge-mcp --transport stdio

# Lancement en mode HTTP (pour API REST)
neuroforge-mcp --transport http --port 3333

# Configuration via variables d'environnement
export NEUROFORGE_URL="http://localhost:1234"
export NEUROFORGE_API_KEY="nf-votre-cle"
neuroforge-mcp

Capacités MCP exposées

  • 🔧 Tools
    • neuroforge_infer — inférence sur modèle local
    • neuroforge_load_model — charger un modèle en mémoire
    • neuroforge_download — télécharger un modèle GGUF
  • 📚 Resources
    • neuroforge://models — catalogue de modèles
    • neuroforge://loaded — modèles en mémoire
    • neuroforge://downloads — téléchargements actifs
  • 💬 Prompts
    • code-review — revue de code avec modèle local
    • translate — traduction multilingue
    • summarize — résumé de documents
